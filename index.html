nana-vm-backup

nana-vm-backup is a personal, non-commercial backup job. Its owner uses it to keep an encrypted nightly backup of their own server in their own Google Drive.

  • Access is limited to files the app itself creates (drive.file scope). It cannot see or change any other file in the Drive.
  • Everything is encrypted on the owner's server before upload; Google stores only encrypted data.
  • It runs unattended on the owner's server. There is no website login and no public sign-up.
  • It is not offered to the general public.
