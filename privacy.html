Privacy Policy — nana-vm-backup

Last updated: 7 October 2026

What the app is

nana-vm-backup is a personal backup job that runs only on its owner's server. It is used by the owner to store backups of that server in their own Google Drive. It is not offered to the public.

What Google data it accesses

With the user's consent, the app requests the https://www.googleapis.com/auth/drive.file scope. This gives access only to files and folders the app itself creates. The app cannot read, list or change any other content of the user's Google Drive.

How the data is used and stored

  • The app uploads encrypted backup archives of the owner's server to the owner's own Google Drive, keeps recent versions and deletes old versions it created.
  • Archives are encrypted on the server before upload; the encryption keys never leave the owner's control.
  • OAuth tokens are stored only on the owner's server and are never shared.

Sharing

Google user data is not sold, not used for advertising and not shared with any third party.

Limited Use

The use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's backup folder in Google Drive removes all data the app has stored there.
